# 手绘涂绘动效（插画 → 动态镜头）

把**一张静态插画**渲染成一个**"正在被画出来"的动态镜头**。核心卖点是上色过程：不是滤镜、不是整体淡入，而是**一支画笔沿路径游走，走过的地方才上色**——一笔一笔、带停顿，并有可见的笔尖和湿边。

## 它做什么（一条时间轴）
1. **打底**：纸张纤维纹理 + 静态颗粒 + 暗角。
2. **线条逐笔画出**（draw-on）：沿一个扫掠方向，把底图里的铅笔/墨线一段段"画"出来。
3. **画笔游走式上色**（核心）：两遍叠色——第一遍斜向铺淡底（62%），第二遍换向加深（44%）；笔触被切段并带停顿，笔尖处压湿痕，前沿一圈湿边加深。
4. **收尾**：画面缓慢"呼吸/摆动"（内部真运动，非推拉镜头）+ 浮尘/雨等粒子 + 手写体字幕淡入淡出 + 结尾洗白转场。

## 输入 / 输出契约
- **输入 A**：一张插画（建议 16:9）。来源不限——生图工具、用户上传、手绘扫描都行。
- **输入 B**：一份 JSON 配置（相对路径以该 JSON 所在目录为基准）。**最小配置只需 `img` 和 `dur`**，其余全部有默认值。
- **输出**：一个 mp4（h264，无音轨）。旁白/配乐属于另一条流程，本技能不含。

## 快速开始
```bash
pip install -r requirements.txt          # 另需系统里有 ffmpeg / ffprobe
cd scripts

# 1) 先看几帧（快，不编码）—— !每次改参数后都先这样看一眼
python3 render.py --config ../examples/scene_example.json --preview 1.0,2.5,4.0,6.0

# 2) 满意了再渲染整镜
python3 render.py --config ../examples/scene_example.json

# 3) 自检（必做，见下"自检门"）
python3 qc.py ../examples/shot_example.mp4 --frames 1.5,3,5,7.5
python3 qc.py --config ../examples/scene_example.json --metrics
```
`--preview` 会渲染到 `<config目录>/preview/`；`render.py` 支持的覆盖参数：`--out --seed --dur --crf --preset`。

## 核心约束（不遵守效果会崩）
写进引擎是为了效率，但**这些约束改动时极易踩**，务必保留：
- **颗粒用"全片同一张静态版"**（引擎已内置）。改成逐帧随机颗粒会让 H.264 单帧编码从 ~25ms 暴涨到 ~3500ms。
- **动效时间一律按秒**。历史上粒子/字幕混用"帧序号"和"秒"，导致字幕完全不显示。
- **长渲染必须前台同步跑**。沙箱里后台(`nohup`)进程会在命令结束后被挂起。
- **上色时长占镜头 50~60%**。太低会退回"整盆水彩泼上去"的观感。
- 完整清单见 `references/pitfalls.md`——**改引擎前先读一遍**。

## 调参（最常动的几个）
| 想要的效果 | 调什么 |
|---|---|
| 上色还像"整盆泼" | 调大 `strokes1`（切更碎）、`col_frac` 提到 0.55~0.65、或减小 `brush1`（笔更细） |
| 更"手绘/更脏" | 提高 `grain`、`live_amp`、`soft` |
| 渲染更快 | `preset=ultrafast`、`crf=20~22`；先 `--preview` 试 |
| 完全复现某次效果 | 记下 `seed` + 全部参数 |
其余字段（画面/转场/粒子/字幕/编码）见 **`references/params.md`**。

## 工作流示例

**示例 A · 单镜**：按上面"快速开始"跑。适合给一篇文章/一条内容配一张动态插图。

**示例 B · 多镜拼成一支短片**
1. 为每个镜头各写一份 config（不同 `img` / `seed` / `texts`），依次渲染成 `seg_1.mp4 … seg_N.mp4`。
2. 无音拼接：
```bash
printf "file '%s'\n" seg_1.mp4 seg_2.mp4 seg_3.mp4 > concat.txt
ffmpeg -y -f concat -safe 0 -i concat.txt -c copy film_silent.mp4
```
3. （可选）加音轨——旁白可用 TTS、配乐可程序化合成，属**外部流程**；做好后：
```bash
ffmpeg -y -i film_silent.mp4 -i audio.wav -c:v copy -c:a aac -b:a 192k -shortest final.mp4
```

## 自检门（每个镜头渲染后必做）
`python3 qc.py <mp4>` 应满足：探针字段齐全（分辨率/帧率/时长）、`decode: OK`。
`python3 qc.py --config <cfg> --metrics` 应显示上色是**阶梯式推进**：每个采样点"新增大块数"在 1~8、偶有 `new%≈0` 的停顿采样、覆盖率单调升到 100%。
若"新增大块数"经常是几十（满屏散点）→ 说明在"漫开"，回去调大 `strokes1` / 放慢 `col_frac`。

## 产出与复现
- 产物默认落在 config 的 `out` 字段（相对 config 目录）。
- 想复现：固定 `seed` 并保存当次全部参数。注意**底图本身若由生图模型产生则不可复现**——把最终图存下来即可。
