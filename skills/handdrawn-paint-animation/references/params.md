# 参数手册

所有输入集中在**一份 JSON** 里（见 `examples/scene_example.json`）。相对路径以该 JSON 所在目录为基准。

## 输入 / 输出
| 字段 | 默认 | 说明 |
|---|---|---|
| `img` | — (必填) | 底图路径（一张插画，建议 16:9） |
| `out` | `out/shot.mp4` | 输出视频路径 |
| `size` | `[1920,1080]` | 输出分辨率 |
| `fps` | `24` | 帧率 |
| `dur` | — (必填) | 镜头时长（秒） |

## 节奏（最影响观感的一组）
| 字段 | 默认 | 说明 |
|---|---|---|
| `ink_dur` | `1.5` | "线条逐笔画出"的耗时（秒） |
| `col0` | `ink_dur*0.7` | 开始上色的时刻（秒），略早于线条画完更连贯 |
| `col_frac` | `0.55` | **上色耗时占镜头时长比例**（与 `col_dur` 二选一，`col_dur` 优先） |
| `col_dur` | — | 直接指定上色耗时（秒），会 clamp 到 3.6~6.5 |
| `strokes1` | `22` | 第一遍（淡底）切成几段笔触 |
| `strokes2` | `10` | 第二遍（加深）切成几段笔触 |
| `brush1`/`brush2` | `H/8`、`W/6` | 两遍的笔刷行距（越大笔越"宽"、笔数越少） |
| `ink_angle` | `40` | 线条"画出来"的扫掠角度（度） |

## 画面质感
| 字段 | 默认 | 说明 |
|---|---|---|
| `soft` | `0.4` | 底图柔化（高斯），让画面更像手工而非数字锐利 |
| `fit` | `true` | 非 16:9 底图按 cover 居中裁剪 |
| `seed` | `1` | 随机种子。**固定它可复现同一效果** |
| `paper_base` | `[240,235,224]` | 纸的底色 RGB |
| `grain` | `0.018` | 颗粒强度（胶片/纸张颗粒） |
| `vig` | `0.22` | 暗角强度 |
| `live_amp` | `5.0` | "呼吸/摆动"位移幅度（像素）；0 = 不呼吸 |

## 转场 & 特效
| 字段 | 默认 | 说明 |
|---|---|---|
| `wipe0` / `wipe_dur` | `dur-0.7` / `0.7` | 结尾"洗白"转场的起始时刻/时长 |
| `overlays` | `[]` | 环境特效，元素如 `{"type":"dust","n":30,"seed":11}`；type 可选 `dust`(浮尘) / `rain`(雨) / `scratch`(划痕)，可加 `alpha`/`ang`/`period` |
| `texts` | `[]` | 字幕，元素如 `{"str":"文本","t0":2.4,"hold":3.0}`；可加 `font`/`size`/`pos`(0~1 相对坐标)/`anchor`(`mm`居中等)/`color`/`stroke`/`stroke_width`/`fade` |

## 编码
| 字段 | 默认 | 说明 |
|---|---|---|
| `crf` | `18` | 画质（越小越清晰、文件越大） |
| `preset` | `veryfast` | x264 速度档；出片慢可改 `ultrafast` |

## 调参口诀
- **上色还是像"整盆泼上去"** → 调大 `strokes1`（切得更碎）、把 `col_frac` 提到 0.55~0.65、或减小 `brush1`（笔更细）。
- **太慢/太平、看不到"一笔一笔"** → 调小 `strokes` 数、略降 `col_frac`。
- **更"手绘/更脏"** → 提高 `grain`、`live_amp`、`soft`。
- **渲染太慢** → `preset=ultrafast`、`crf=20~22`；或用 `--preview` 先看几帧再决定。
- **要完全复现某次效果** → 记下当时的 `seed` + 全部参数。
